# 推广披露与独立性声明

## 推广链接

本站机场评测页、[机场对比](/airport/compare)、[性价比机场](/airport/best-value)和[机场优惠码](/airport/coupons)中的“官网”“注册”类链接，多数是带有推广标识的注册链接。你通过这些链接注册并付费时，本站可能获得佣金。这不会增加你需要支付的价格。

这类链接统一经由本站的 `/go/` 地址跳转，并标注 `rel="sponsored nofollow"`。

## 优惠码

优惠码来自各机场评测页或机场官方公开信息。优惠随时可能调整或失效，请以结算页实际显示为准。页面上的“评测更新”日期指评测页的更新时间，不代表优惠码在该日期被重新核对。

## 评测与排序

- [机场对比](/airport/compare)、[性价比机场](/airport/best-value)按评测页中的起步价格整理，排序依据写在页面里，不按佣金排序。
- 评测页同时列出优点与缺点；已出现跑路或失联迹象的机场进入[跑路预警](/airport/paolu)，不会出现在对比、性价比和优惠码页面中。
- 速度、解锁情况会随时间、地区、运营商和节点变化，页面中的测试结果仅代表测试当时的情况。

## 联系方式

发现信息错误、优惠失效或机场状态变化，可通过 [关于与评测方法](/about) 页面中的联系方式告知，我们核实后更新。
