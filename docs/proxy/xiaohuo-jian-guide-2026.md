## 小火箭节点选择技巧

### 节点命名规则解读

机场节点通常包含以下信息：

```
🇭🇰 香港-IEPL-01 | 倍率:0.5 | 流媒体解锁
```

**解读：**
- 🇭🇰 = 节点地区（香港）
- IEPL = 线路类型（专线）
- 01 = 节点编号
- 倍率:0.5 = 流量倍率（使用1GB扣除0.5GB流量）
- 流媒体解锁 = 特殊功能（可以看Netflix等）

### 如何选择最快的节点

**按使用场景选择：**

**日常浏览、社交媒体**
- 推荐：🇭🇰 香港节点
- 延迟：10-50ms
- 速度快，连接稳定

**看YouTube、Netflix**
- 推荐：🇸🇬 新加坡、🇺🇸 美国节点
- 选择标注"流媒体解锁"的节点
- 支持4K视频播放

**访问日本网站、下载**
- 推荐：🇯🇵 日本节点
- 适合访问日本网站和服务

**访问欧美网站**
- 推荐：🇺🇸 美国、🇬🇧 英国节点
- 适合访问美国、欧洲网站

**游戏加速**
- 推荐：专线节点（IEPL/IPLC）
- 延迟更低，更稳定

### 节点测速方法

小火箭内置测速功能：

1. 在首页节点列表
2. 点击右上角 **"⚡️ 连通性测试"**
3. 等待测试完成
4. 节点列表会显示延迟（数字越小越快）
5. 选择延迟最低的节点

**技巧：** 定期测速（每周1-2次），因为节点状态会变化。

## 小火箭分流规则设置

分流规则可以让你的流量智能分配：国内网站直连，国外网站走代理，节省流量并提升速度。

### 快速设置分流规则

**方法一：使用机场提供的规则（推荐）**

很多机场的订阅链接已经包含分流规则，导入后自动生效。

**方法二：手动导入规则**

1. 打开小火箭
2. 点击底部 **"配置"**
3. 点击右上角 **"+"**
4. 选择 **"从URL下载"**
5. 输入规则地址（推荐ACL4SSR规则）：
   ```
   https://raw.githubusercontent.com/ACL4SSR/ACL4SSR/master/Clash/config/ACL4SSR_Online.ini
   ```
6. 点击 **"下载"**
7. 下载完成后，点击该配置文件
8. 选择 **"使用配置"**

### 分流规则效果

配置规则后的效果：
- ✅ 国内网站（淘宝、微信、百度）→ 直接连接（不走代理）
- ✅ 国外网站（Google、YouTube、Facebook）→ 走代理
- ✅ 节省机场流量
- ✅ 提升国内网站访问速度

## 小火箭常见问题解决

### 1. 小火箭无法连接？

**解决方法：**

**检查网络**
- 确保Wi-Fi或4G/5G网络正常
- 尝试切换网络

**更新订阅**
- 右滑订阅条目 → 点击"更新"
- 机场可能更换了节点

**切换节点**
- 当前节点可能失效
- 选择其他节点尝试

**重启小火箭**
- 完全关闭App（上滑退出）
- 重新打开

**检查套餐**
- 登录机场官网
- 查看套餐是否过期或流量用完

### 2. 小火箭连接后无法上网？

**解决方法：**

**检查全局路由**
- 打开小火箭
- 点击底部"配置"
- 确保"全局路由"设置正确
- 推荐：配置（使用配置文件）或代理

**关闭干扰应用**
- 关闭其他VPN应用
- 关闭系统自带VPN

**重置网络设置**
- 设置 → 通用 → 传输或还原iPhone → 还原 → 还原网络设置
- ⚠️ 会清除WiFi密码

### 3. 小火箭速度很慢？

**优化方法：**

**选择更快的节点**
- 使用测速功能找到最快节点
- 选择距离近的地区（香港、日本、新加坡）

**避开高峰期**
- 晚上8-11点是使用高峰
- 尝试其他时间段

**检查本地网络**
- 测试本地网速是否正常
- 尝试切换Wi-Fi和移动数据

**升级套餐**
- 便宜套餐通常人多速度慢
- 考虑升级到专线套餐

**更换机场**
- 当前机场可能超售
- 参考：[2026年稳定机场推荐](/airport/best-airport-2026.html)

### 4. 小火箭订阅无法更新？

**解决方法：**

**检查订阅链接**
- 登录机场官网
- 重新复制订阅链接
- 删除旧订阅，添加新订阅

**网络问题**
- 有些订阅链接需要翻墙才能更新
- 先连接任意一个可用节点
- 再更新订阅

**机场维护**
- 联系机场客服
- 等待机场恢复

### 5. 小火箭共享账号无法下载？

**解决方法：**

**账号已被锁定**
- 共享账号使用人数过多会被Apple锁定
- 尝试其他共享账号
- 或购买自己的美区账号

**切换下载方式**
- 使用方法一：购买正版（$2.99）
