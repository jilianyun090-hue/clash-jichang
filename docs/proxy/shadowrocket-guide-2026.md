## Shadowrocket高级配置

### 配置分流规则

**什么是分流规则？**
分流规则决定哪些网站走代理，哪些直连，实现智能加速。

**内置规则使用：**

1. 点击"配置" tab
2. 点击当前配置文件右侧的"i"图标
3. 选择"HTTPS解密"打开
4. 回到配置页面
5. 点击"默认配置"→"编辑配置"
6. 在"规则"部分可以看到内置规则

**推荐规则订阅：**

```
https://raw.githubusercontent.com/Johnshall/Shadowrocket-ADBlock-Rules-Forever/release/lazy.conf
```

**导入规则：**
1. 复制规则链接
2. 点击"配置"
3. 点击右上角"+"
4. 选择"从URL下载"
5. 粘贴链接并下载

### 去广告配置

**方案一：使用规则订阅**

导入带广告过滤的规则配置（推荐上方规则链接）

**方案二：手动添加广告规则**

1. 点击"配置" → "模块"
2. 添加广告过滤模块
3. 启用模块

### 自定义规则

**添加特定域名规则：**

1. 点击"配置" → "编辑配置"
2. 滚动到[Rule]部分
3. 添加规则，格式如下：

```
# 强制走代理
DOMAIN-SUFFIX,google.com,PROXY
DOMAIN-SUFFIX,youtube.com,PROXY

# 强制直连
DOMAIN-SUFFIX,baidu.com,DIRECT
DOMAIN-SUFFIX,qq.com,DIRECT

# 屏蔽广告
DOMAIN-SUFFIX,ad.com,REJECT
```

## Shadowrocket常见问题

### Q1: Shadowrocket连接后无法上网？

**解决方法：**

1. **检查订阅是否过期**
   - 登录机场官网查看
   - 续费或更换机场

2. **更新订阅**
   - 下拉刷新订阅
   - 重新导入订阅链接

3. **切换节点**
   - 某些节点可能失效
   - 进行延迟测试选择其他节点

4. **检查全局路由**
   - 确保设置为"配置"或"代理"
   - 不要选择"直连"

5. **重启Shadowrocket**
   - 完全关闭应用
   - 重新打开并连接

### Q2: Shadowrocket提示证书错误？

**原因：** HTTPS解密功能需要安装证书

**解决方法：**

1. 点击"配置" → "证书"
2. 点击"生成新的CA证书"
3. 点击"安装证书"
4. 按提示完成证书安装
5. 前往"设置" → "通用" → "关于本机" → "证书信任设置"
6. 打开Shadowrocket证书的开关

### Q3: 部分App无法使用？

**原因：** 某些App检测到VPN会拒绝服务

**解决方法：**

1. 使用分流规则
2. 将该App的域名添加到直连规则
3. 或在使用该App时临时关闭Shadowrocket

### Q4: 速度慢怎么办？

**优化方法：**

1. **选择最快节点**
   - 进行延迟测试
   - 选择延迟低的节点

2. **更换线路**
   - BGP中转 > IPLC专线 > 普通直连
   - 选择距离近的节点（香港、日本）

3. **检查网络环境**
   - WiFi信号强度
   - 本地网络速度

4. **升级机场套餐**
   - 选择更高带宽的套餐
   - 参考[机场推荐](/airport/)

### Q5: Shadowrocket需要一直开着吗？

**答案：** 根据需要

- ✅ 访问国外网站时开启
- ✅ 使用国际App（ChatGPT、Twitter）时开启
- ❌ 访问国内网站时可关闭（节省流量）
- ❌ 不使用时关闭（节省电量）

### Q6: 多台设备能共用一个订阅吗？

**取决于机场规则：**

- 大部分机场支持3-10台设备同时使用
- 但同一订阅在多台设备上会共享流量
- 超过设备数限制可能导致封号

**建议：**
- 家人共享：选择不限设备数的机场
- 个人使用：2-3台设备完全够用

### Q7: Shadowrocket会被封号吗？

**安全使用建议：**

- ✅ 不要分享订阅链接给他人
- ✅ 合理使用流量，避免异常
- ✅ 不要用于违法活动
- ✅ 选择正规机场

**风险等级：**
- 个人正常使用：风险极低
- 商业化分享：高风险
