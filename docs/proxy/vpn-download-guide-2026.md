## 重要说明：VPN客户端 vs 机场订阅

很多人对"VPN下载"存在误解，这里先澄清两个概念：

### 1. VPN客户端/代理工具（本文重点）

**这是什么：** 安装在你设备上的软件，用于连接VPN服务器或机场节点

**代表软件：**
- Windows: Clash Verge, V2rayN
- Mac: ClashX Pro, Surge
- iOS: Shadowrocket (小火箭), Quantumult X
- Android: Clash Meta, V2rayNG

**特点：**
- ✅ 免费开源（大部分）
- ✅ 仅提供连接功能
- ❌ 需要配合机场订阅或VPN服务使用
- ❌ 客户端本身不能翻墙

### 2. 机场订阅/VPN服务（需要购买）

**这是什么：** 提供翻墙节点的服务商

**特点：**
- 需要付费购买（月付¥8-30）
- 提供订阅链接或配置文件
- 导入到客户端后才能使用

**理解：** 客户端就像"播放器"，机场订阅就像"会员账号"，两者缺一不可。

## Linux VPN下载与配置 {#linux-vpn下载}

### Clash for Linux

**适合人群：** Linux用户、开发者

**安装方法：**

```bash
# 下载Clash
wget https://github.com/Dreamacro/clash/releases/download/vX.X.X/clash-linux-amd64-vX.X.X.gz

# 解压
gunzip clash-linux-amd64-vX.X.X.gz

# 重命名
mv clash-linux-amd64-vX.X.X clash

# 添加执行权限
chmod +x clash

# 创建配置目录
mkdir -p ~/.config/clash

# 下载订阅配置
# 将订阅链接内容保存为 config.yaml

# 运行Clash
./clash -d ~/.config/clash
```

**配置系统代理：**
- HTTP代理：`http://127.0.0.1:7890`
- SOCKS5代理：`socks5://127.0.0.1:7891`
