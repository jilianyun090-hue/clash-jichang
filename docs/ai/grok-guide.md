Grok 是由 Elon Musk 主导的 xAI 公司发布的 AI 模型。与主打"信息整合"的传统助手不同，Grok 在推理、编程、实时搜索和互动体验上各有特色，还引入了 AI 陪伴系统 Grok Ani。

## Grok 当前模型

据 xAI 官方模型文档（2026 年 10 月核对），文本模型中最新、能力最强的是 **grok-4.7**，其后依次为 grok-4.6、grok-4.5、grok-4.3。另有图像（grok-imagine-image 系列）、视频（grok-imagine-video 系列）和语音模型。网页版与 App 里实际可用的模型、额度和价格以 [grok.com](https://grok.com) 与官方订阅页为准。来源：[xAI 模型文档](https://docs.x.ai/docs/models)。

## 核心亮点

| 能力 | 说明 | 适用场景 |
| :--- | :--- | :--- |
| **Think Mode 深度推理** | 基于"第一性原理"的推理机制，给出更严谨的解答 | 学术研究、工程设计、逻辑推导 |
| **多模态输入** | 支持文字和图像输入，可解析公式、设计图 | 图表分析、数学解题、设计审查 |
| **DeepSearch 实时搜索** | 集成 X 平台与网络数据，解答实时问题 | 赛事预测、新闻动态、市场分析 |
| **代码能力** | 支持生成、调试和重构代码 | 编程开发、代码审查 |
| **AI 陪伴（Grok Ani）** | 3D 动漫角色互动，支持语音和动态表情 | 沉浸式对话体验 |
| **长上下文** | 支持较长的上下文窗口，具体长度以官方文档为准 | 论文精读、长篇翻译 |

Grok 需要海外网络环境才能访问。可以参考本站收录的[机场推荐](/airport/)，选择支持美国节点的服务，并建议先买月付套餐自己测试。

### 1. Grok 网页

**方式一：Grok 官网直接访问**

访问 [grok.com](https://grok.com/)，支持使用 Google 账号、X 账号、Apple 账号或邮箱注册登录。网页版无需下载应用，适合日常办公和内容创作。

**方式二：通过 X 平台访问**

登录 [x.com/i/grok](https://x.com/i/grok)，在左侧菜单栏找到 Grok 入口。如果没有 X 账号，需要按 X 的要求完成注册和验证。

### 2. Grok 移动 App

- **iOS 用户**：需使用美区 Apple ID，参考[iOS 客户端下载教程](/airport/client-ios)中的 Apple ID 切换方法。
- **Android 用户**：建议通过 Google Play 下载官方版本，或参考 [Android 客户端教程](/airport/client-android)配置代理后下载。

### 3. 合租方案

如果不想自行注册订阅，也可以通过合租平台获取 Grok 账号，合租存在账号被收回的风险，请先阅读[合租避坑指南](/account/how-to-share)。

## Grok Ani 陪伴系统

Grok Ani 是 Grok Companions 功能中的 3D 动漫角色，支持语音和文本对话，具有动态表情互动体验。

### 启用步骤

1. 打开 Grok 应用并登录账号。
2. 进入"设置"菜单，启用 Companions 功能。
3. 从侧边栏选择 Ani，进入语音或文本对话模式。
4. 通过对话提升关系等级，解锁更多互动内容。

## 常见问题

### Q: Grok 免费版能用多少次？

免费版每日有一定的使用次数限制，适合轻度体验。如需频繁使用 Think Mode 与 DeepSearch，建议升级到 SuperGrok。

### Q: 国内无法访问 Grok 怎么办？

需要通过合规可用的网络环境连接海外网络，可参考[机场推荐](/airport/)，优先选择月付并自行测试稳定性。

### Q: Grok Ani 在哪些平台可用？

目前 Companions 功能主要在 Grok 移动 App 中开放，桌面端支持情况以官方更新为准。
