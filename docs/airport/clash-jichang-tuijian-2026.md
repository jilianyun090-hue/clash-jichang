## Clash机场订阅导入教程

### 方法一：Clash Verge 一键订阅导入

1. 在机场网站复制订阅链接
2. 打开 Clash Verge Rev
3. 点击「订阅」→「新建」→「粘贴订阅链接」
4. 点击「更新订阅」
5. 选择节点，开启系统代理

### 方法二：Clash Meta 订阅导入

1. 复制机场订阅链接
2. 打开 Clash Meta
3. 配置 → 添加订阅
4. 粘贴链接并更新
5. 启用代理即可

## Clash机场常见问题

### Q1: Clash订阅导入后无法连接？

**A**: 检查以下几点：
1. 确认订阅链接是否正确复制
2. 尝试更新订阅获取最新节点
3. 检查本地代理端口是否被占用（默认7890）
4. 尝试切换不同节点测试

### Q2: Clash节点延迟很高怎么办？

**A**: 解决方法：
1. 点击「延迟测试」重新测速
2. 选择延迟较低的节点
3. 避开晚高峰时段（20:00-23:00）
4. 联系机场客服反馈节点问题

### Q3: 哪些机场支持Clash UDP转发？

**A**: 本文推荐的专线机场（极连云、边界云、飞猫云等）均支持UDP转发，适合玩游戏和使用语音通话。

### Q4: Clash订阅需要经常更新吗？

**A**: 建议每周更新一次订阅，机场会定期添加新节点或调整线路。Clash Verge 可以设置自动更新。
